# JoAmy Installer

Verbindet dein Home Assistant mit [joamy.uk](https://joamy.uk): Nach einmaliger
Kopplung per Kurz-Code installiert sich jeder Baustein automatisch (lädt das
Baustein-Paket, sichert die alte Version nach `/config/joamy_backup/`, entpackt
nach `/config/custom_components/` und stößt den Config-Flow an).

**Installation:** Einstellungen → Add-ons → Add-on-Store → oben rechts ⋮ →
Repositories → `https://github.com/Jochi000/addons` hinzufügen → „JoAmy Installer"
installieren → starten → Kopplungscode aus der Add-on-Seite auf
joamy.uk eingeben.
